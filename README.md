💻 Meu Portfólio Pessoal

📖 Sobre o Projeto

Este repositório contém o código-fonte do meu portfólio pessoal, desenvolvido para centralizar meus principais projetos, competências técnicas, histórico profissional e formas de contato direto para oportunidades de trabalho ou parcerias.

O objetivo do design e arquitetura foi criar uma experiência rápida, moderna, responsiva e acessível em qualquer dispositivo.

🚀 Como Executar Localmente

Passo a passo

# 1. Clone este repositório
git clone https://github.com/Golskilamaster09/portfolio.git

# 2. Acesse a pasta do projeto
cd portfolio

# 3. Caso use Node.js/npm:
npm install

# 4. Inicie o servidor de desenvolvimento
npm run dev
# (ou abra diretamente o arquivo index.html no navegador caso seja HTML puro)
